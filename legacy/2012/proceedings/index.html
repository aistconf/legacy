Доклады АИСТ'2012

Доступна программа конференции.

Миникурсы (по 3 лекции)

Ольга Баринова (МГУ, Москва). Компьютерное зрение

  1. Компьютерное зрение. Задачи и применения;
  2. Графические модели в компьютерном зрении;
  3. Текущие проекты по компьютерному зрению в МГУ и MS Research.

Юрий Катков (НИУ ИТМО, Санкт-Петербург). Прагматическое введение в Semantic Web и Linked Data

  1. Стандарты представления данных и запросов к ним, наиболее часто используемые в современном вебе: часть 1, часть 2;
  2. Источники данных, доступные для использования разработчиками ПО;
  3. Программные инструменты и библиотеки для обработки и публикации этих данных, поиск дополнительной информации.

Максим Дубинин (NextGIS, Москва). Геоинформационные системы

  1. Геоданные: особенности, основные источники, ПО для работы с ними.
  2. Непараметрические классификаторы для анализа данных дистанционного зондирования.
  3. Методы максимальной энтропии для пространственного нишевого анализа.
